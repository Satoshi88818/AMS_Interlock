AntimatterSim v10 — Risk-Prioritized Roadmap

This roadmap restructures the v10 "seven pillars" around patient-safety impact and regulatory exposure rather than technical novelty. Items are grouped into four tiers, followed by suggested sequencing.

Tier 0 — Must exist before any of this ships (safety/regulatory foundation)

Nothing in later tiers should be built on top of a system that lacks these. These are preconditions, not features.

Suggested Sequencing

Now: Tier 0 documentation fixes (especially ZKP/DP language) — cheap, removes the biggest credibility/regulatory risk immediately.

Next: Tier 0 interlock design + Tier 1 TensorRT DIR (independent, low-risk, ships value fast).

Then: Tier 1 Pareto planning with a real clinician-review workflow, followed by edge inference — gated on the interlock spec being done first.

Later, rescoped: JAX differentiable physics (partial-differentiability approach) and federated learning (fixed privacy accounting).

On hold pending a real driver: planetary multi-region deployment, Wasm edge runtime.

Cut or fundamentally rescope: the "safety proof" framing of zk-SNARKs.

Next candidate artifact: a formal state-machine spec for the Tier 0 edge-cloud interlock (states, transitions, fallback behavior on edge/cloud disagreement) — highest leverage next step since later tiers depend on it.
